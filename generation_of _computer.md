(PAST)  1) first generation computer (1945-1954).

→This generation computers are called vacuum tubes / thermionic values based machine. These computer uses circuitry and magnetic drums for memory. For input these computer uses punched cards and paper tape and for output it displayed a printout. These computers mainly uses binary coded language for input & output and can perform only one task at a time. In these generation Machine level language binary has been developed. which can perform 1s and 2s. These computer were the difficulest computer to program.

The input and output was done the same like 1st generation like: For input punched card and output printout, from this generation computer the computer uses assembly language for the instruction. Assembly language uses memonic codes like: ADD for addition and SUB for subtraction. From this generation computer they change the computational time to millisecond to microsecond.
